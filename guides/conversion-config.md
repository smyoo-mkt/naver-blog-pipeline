# 전환 설정 (conversion-config)

> 전환 접점·출처·바이라인의 단일 진실 공급원(SSOT). 에이전트는 CTA·링크·출처를 여기서만 가져온다.

---

## 전환 목표

- **1차: 사업자 세무기장 전환** (법인 기장 우선 → 개인사업자 기장 차순)
- 종소세/부가세 환급은 보조 전환(빠른 리드)으로만 사용
- **재산제세(상속·증여·양도)는 전환 대상에서 제외.** 해당 주제 글을 쓰더라도 CTA는 기장 상담으로 연결하지 않고 일반 정보 + 톡톡 문의 수준에서 마무리한다.

## CTA · UTM 테이블

| 글 유형 | 1차 CTA | 링크(UTM 부착) |
| --- | --- | --- |
| 법인 기장/법인전환 | 네이버 톡톡 → 무료 세무진단 | 톡톡 우선. 외부 폼 사용 시 `?utm_source=naver_blog&utm_medium=post&utm_campaign=corp_book&utm_content=<slug>` |
| 개인사업자 기장 | 네이버 톡톡 → 무료 세무진단 | `...&utm_campaign=indiv_book&utm_content=<slug>` |
| 종소세/부가세 환급 | 더낸세금 환급 | `...&utm_campaign=refund&utm_content=<slug>` |
| 지역·업종 롱테일 | 네이버 톡톡 + 가까운 지점 플레이스 | 플레이스 연계 |

규칙: 네이버 톡톡을 최우선(생태계 내부, 감점 없음). 외부 상업 링크는 글당 과하지 않게, 반드시 UTM 부착. `<slug>`는 글 슬러그로 치환.

**외부 상담신청 폼 기본 URL**: `https://www.heumtax.com/consulting`
- 최종 링크 = 기본 URL + 위 표의 UTM. 예(법인 기장): `https://www.heumtax.com/consulting?utm_source=naver_blog&utm_medium=post&utm_campaign=corp_book&utm_content=<slug>`
- 기본 배치: **네이버 톡톡 우선 + 외부 폼 병행.** 톡톡을 먼저 노출하고, 외부 폼은 보조 버튼으로 함께 둔다.

## CTA 문구 (후킹 문구 + 버튼 문구) 가이드

모든 글에는 CTA 링크가 들어간다. 링크는 위 테이블에서 가져오되, **후킹 문구와 버튼 문구는 SEO 검수 단계(naver-seo-editor)가 글마다 2~3안씩 추천**하고 운영자가 게이트2에서 택1한다.

- **후킹 문구**(상담신청 유도 문장, 1~2문장): 독자의 현재 불안·니즈(예: "환급받고 소명요구 올까 봐 걱정")를 먼저 짚고 → 상담으로 얻는 이득을 제시한다. 글의 각도·독자와 맞물려야 한다.
- **버튼 문구**(6~14자 내외 행동유도): 네이버 톡톡이 1차 접점이면 "톡톡" 명시 가능. 진입장벽을 낮추는 표현(무료·1분·바로) 활용. 예: `무료 세무진단 받기`, `톡톡으로 상담 문의`, `1분 세무진단 신청`.
- **산출 형식**(review.md의 "CTA 문구 추천" 섹션): 후킹 2~3안 + 버튼 2~3안, 각 안마다 추천 이유 1줄. 본문 중간용/말미용을 구분해도 좋다.
- **금지**: 절세·환급 보장 단정, 과장광고, 세무사법 오인 표현, 허위 혜택(실제와 다른 "무료"/기간 한정 등).

### 카피 소구 방향 (문의·수임 데이터 근거, 2026-08-03 추가)

실측 수임률(2025-03~2026-07, 문의 6,966건, 전체 평균 21.2%)에 근거한 지침이다. 상세는 `work/inquiry-data-implications-2026-08.md`.

**권장 소구 4가지**

| 소구 | 근거 수임률 |
| --- | --- |
| **"지원금·세제혜택까지 먼저 챙기는"** | 기장 문의 + 지원금 언급 = **47.1%** (전체 최고 세그먼트) |
| **전문성** ("꼼꼼히·챙겨주는·알아서") | 절세 적극형 표현 언급 고객 **31.3%** |
| **응답성** (연락이 닿는·바로 답하는) | 이관 사유 1위가 "전화를 안 받는다"류 불만 (이관 32.0%) |
| **개업 초기 케어** ("첫 세무사") | 신규기장 × 창업 1년 미만 **40.7%** |

⚠ **"지원금"은 카피에만 쓰고 키워드로 노리지 말 것.** 지원금 자체가 목적인 문의는 수임률 5.7%(최하위)다. 가치 있는 것은 "지원금을 원하는 사람"이 아니라 **"지원금까지 챙겨주는 세무사를 원하는 기장 고객"**이다.

**배제 소구**

- **가격·최저가·저렴함** — 가격문의 14.9%, 비용부담 호소 고객 14.7%. 가격 계열 광고 키워드는 7~16%로 전면 감액 후보(세무기장료 7%·법인기장료 10%). 리포트 결론 "가격 소구는 비효율"
- **신고 대행 소구** ("신고 대신 해드립니다") — 신고대리 문의 11.4%, 신고기한 임박 10.8%, 종소세신고 키워드 0%. **신고·가산세·환급 주제 글이라도 CTA는 신고 대행이 아니라 "매달 관리 = 기장"으로 닫는다**
- **긴급성 소구** ("지금 신청하세요") — 긴급도는 수임률과 무관하고, '긴급' 표시 문의가 오히려 최저(신고기한 임박과 겹침)

**CTA 각도 우선순위** (유도할 문의 의도 순)

1. 신규기장 (32.7%) — 특히 창업 1년 미만 (40.7%)
2. 세무사이관 (31.3%) — "기존 세무사 불만" 각도
3. 급여/4대보험 (26.8%)
4. 그 외는 평균 이하. 신고대리·경정청구·자산세·정부지원금 유도는 피한다

## 바이라인 레지스트리 (실명·자격 — 채워서 사용)

| 코드 | 표기 | 전문 분야 |
| --- | --- | --- |
| TBD-01 | [세무사명] 세무사 (혜움 OO지점) | 법인 기장 |
| TBD-02 | [세무사명] 세무사 (혜움 OO지점) | 개인사업자·프리랜서 |

> 운영자가 실제 세무사 정보로 교체한다. 라이터는 빈 코드를 추정해 채우지 않는다.

## 글 말미 표준 블록 (면책조항 + 바이라인)

라이터는 모든 글 말미(CTA 다음)에 아래 블록을 그대로 붙인다. 면책조항은 YMYL 필수, 바이라인은 위 레지스트리 코드를 사용한다.

```
※ 본 글은 일반적인 정보 제공을 목적으로 하며, 개별 사안에 대한 세무 자문이 아닙니다. 세법은 작성 시점(YYYY년 기준) 기준이며 이후 개정될 수 있습니다. 구체적인 판단은 반드시 담당 세무사와 상담하시기 바랍니다.

글쓴이 | [바이라인 레지스트리 코드의 표기 그대로]
```

규칙: `YYYY`는 글의 사실 기준연도(research·registry의 `fact_basis_year`)로 치환한다. 바이라인 코드가 아직 TBD면 코드 그대로 두고 추정 정보를 만들지 않는다.
