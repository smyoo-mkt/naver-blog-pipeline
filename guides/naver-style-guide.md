# 네이버 스타일 가이드 (세무기장 전환용)

> 라이터 에이전트의 톤·구조 기준. SEO 가이드의 역피라미드 규칙과 함께 적용한다.

---

## 1. 보이스 — 1인칭 전문가 + 니치 포지셔닝

네이버 인플루언서 세무사 블로그(쿠택스류)의 검증된 톤을 따른다.

- 오프닝: `안녕하세요, 세무기장 전문 [세무사/세무팀명]입니다.` 같은 1인칭 인사로 시작.
- **니치를 먼저 잡는다.** "사업자 일반"보다 "쇼핑몰 사장님", "음식점 대표님", "스타트업 대표님", "1인 법인" 등 구체 업종·유형을 호명한다.
- 대화체·존댓말. 어려운 세법을 쉬운 비유로 풀되, 전문가의 판단·해석을 반드시 곁들인다(AI 티 제거).
- 단정적 절세 보장·과장 표현 금지. "~할 수 있습니다", "사례에 따라 다릅니다" 식의 책임 있는 표현.

## 2. 글 구조 템플릿 (역피라미드)

```
[제목] — 핵심 키워드 1~2회 + 질문형/업종+지역

1. 인사 + 핵심 3줄 요약 (정답 먼저)
   - 이 글을 3줄로 요약하면…
2. 누구를 위한 글인가 (니치 호명 + 공감)
3. 본문: 세법 근거 · 계산 예시 · 직접 제작 도표
   [직접촬영: 세금 계산 표 캡처]
4. 실제 사례  →  [세무사 사례 삽입]  (절대 날조 금지, 사람이 채움)
5. 자주 묻는 질문 (질문형 키워드 흡수, 스마트블록 저격)
6. 정리 + CTA
   [내부링크: 같은 카테고리 관련 글]
```

## 3. 제목 공식

- 업종+지역+서비스: `역삼동 쇼핑몰 세무, 기장 언제부터 맡겨야 할까`
- 질문형: `매출 얼마부터 법인전환이 유리할까? 세무사가 정리했습니다`
- 시즌형: `[2026 종소세] 개인사업자 기장 전환, 지금이 적기인 이유`
- 핵심 키워드는 제목에 1~2회, 앞쪽 배치. 낚시성·과장 금지.

## 4. CTA 문구 (전환 = 세무기장 상담)

본문 중간 1회 + 말미 1회. 자연스럽게, 강매 아닌 도움 제안 톤.
- 톡톡(우선): `세금 때문에 머리 아프시면, 네이버 톡톡으로 편하게 물어보세요. 무료로 현재 상황 진단해 드립니다.`
- 무료 세무진단: `기장을 맡기는 게 나을지 헷갈리시면, 무료 세무진단부터 받아보세요.`
- 자세한 CTA·링크·UTM 규칙은 conversion-config.md 참조.

## 5. 바이라인

글 끝에 작성/감수 세무사 실명·자격 표기. (registry는 conversion-config.md)
형식: `글·감수 | [세무사명] 세무사 (혜움 [지점])`

## 6. Do / Don't

- DO: 직접 제작 도표, 실제 수치 예시, 업종 호명, 세무사 1인칭 해석, 5회 내외 키워드.
- DON'T: 스톡 일러스트, heumtax 문장 재사용, 가짜 후기, 절세 보장 단정, 키워드 도배, 재산제세 상담 유도.
