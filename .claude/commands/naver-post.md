네이버 블로그 글 생산 파이프라인을 실행한다. 전환 목표는 **사업자 세무기장**(법인 우선·개인 차순), 재산제세 제외.

대상 키워드: $ARGUMENTS

다음 순서로 서브에이전트를 호출하되, **휴먼 게이트에서 반드시 멈춘다.**

1. `naver-brief-planner` 호출 → `work/<slug>-brief.md` 생성.
   - ⛔ 게이트 1 (브리프 승인): 의도·각도·CTA를 운영자가 승인할 때까지 대기. 승인 전 진행 금지.
2. (승인 후) `naver-researcher` 호출 → `work/<slug>-research.md`.
3. `naver-writer` 호출 → `work/<slug>-draft.md`.
4. `naver-seo-editor` 호출 → `work/<slug>-review.md` + 체크리스트 + **CTA 문구 추천**(후킹 2~3안 + 버튼 2~3안).
   - ⛔ 게이트 2 (세무사 감수·발행 승인): 세무사가 ① 사실 정확성 ② `[세무사 사례 삽입]` 실제 사례 채우기 ③ 과장표현 제거 ④ CTA 문구(후킹·버튼) 택1을 완료할 때까지 대기. 완료 전 "발행 가능"으로 표시 금지.

각 단계 종료 시 다음 게이트에서 사람이 확인할 항목을 3줄 이내로 요약해 출력한다. 사실 날조·가짜 후기·기존 글 복제는 어느 단계에서도 금지.
